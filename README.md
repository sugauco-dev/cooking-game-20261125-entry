Sizzle & Serve — Bistro Rush: run the lunch rush in a warm neighbourhood bistro. Grill patties, fry baskets, stack burgers and serve them before the order tickets run out. Five combinable recipes, grill and fryer timing with burn risk, escalating rush hour and combo scoring — all in plain canvas and vanilla JavaScript, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD or the arrow keys, press E (or click) to use a station.
